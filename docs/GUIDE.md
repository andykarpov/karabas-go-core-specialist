# Как пользоваться ядром Специалист

Ядро для Karabas Go, Mini и Mini G. Две модели: **Original** (Специалист, 1987) и **MX** (Специалист-MX, 1991). Модель выбирается в OSD, смена модели сбрасывает машину.

## Что положить на SD-карту

В корень: `specialist.kg`. В папку `/specialist`: программы и образы дисков.

| Файл | Куда в OSD | Что это |
|---|---|---|
| `.rks` | RKS file (Menu+F2) | программа, образ кассеты |
| `.odi` | Disk A (Menu+F7), Disk B (Menu+F8) | дискета MX, 800 КБ |
| `.rom`, `.bin` | Monitor (Menu+F4) | свой Монитор для Original, до 12 КБ с C000 |
| `.rom`, `.bin` | MX ROM (Menu+F5) | своё ПЗУ MX, до 48 КБ с 0000 |

Монитор-2 и ПЗУ RAMFOS уже есть внутри `specialist.kg`. Программы и игры в `.rks` есть в комплекте эмулятора [Emu80](https://github.com/vpyk/emu80v4): `dist/spec/sdcard/GAMES`, `dist/specmx/sdcard/exolon`.

## Первый запуск

**Original.** На экране «PROGRAM ?». Нажмите F1, затем Enter, появится «* МОНИТОР ?». Загрузите программу пунктом RKS file: она запустится сама примерно через 0,2 секунды.

**MX.** RAMFOS спрашивает дату: можно просто нажать Enter. Откроется оболочка с RAM-диском, внизу подсказки по клавишам F1–F7. F6 загружает с дискеты в приводе A. Файл `.rks` на MX тоже запускается сам, в обход RAMFOS.

Autorun = Off только загружает `.rks` в память, запускать его надо самому: на Original директивой G Монитора.

## Клавиши

Раскладка позиционная, как QWERTY-режим Emu80: буквы и цифры на своих местах.

| Клавиша ПК | Специалист |
|---|---|
| Shift | НР |
| Enter | ВК |
| Backspace | ЗБ |
| Home | Курсор в начало |
| PgUp | СТР |
| PgDn, End | ПС |
| Ctrl | ПВ (только Original) |
| Insert, Caps Lock | РУС/ЛАТ |
| `=` | `:` |
| `'` | `^` |
| `` ` `` | `@` |
| F1–F11 | F1–F11 (на MX F1–F10) |

F12 — сброс (Reset в OSD), Menu+Esc — OSD. Джойстик работает как клавиши: стрелки, A — пробел, B и Start — Enter.

## OSD

| Пункт | Значения |
|---|---|
| Model (Menu+M) | Original, MX |
| CPU speed (Menu+S) | 2 МГц (как в оригинале), 4 МГц |
| Color (Menu+C) | 8 цветов, 4 цвета, моно (только Original; большинство программ чёрно-белые) |
| Autorun (Menu+A) | запускать `.rks` после загрузки |
| Video | 800 × 600 60 Гц, 720 × 576 50 Гц |

## Диски MX

Образ `.odi`: 80 дорожек, 2 стороны, 5 секторов по 1024 байта, 819200 байт. Запись сохраняется в файл на карте. Настоящий диск с ОС MX на этом ядре ещё не запускали: не нашли образ. Загрузка и запись проверены тестовыми образами (`src/sim/mkboot_odi.py`, `mkboot_rw.py`). Если есть образ с CP/M или RAMFOS, расскажите, что получилось.
