# Как пользоваться ядром Специалист

Ядро для Karabas Go, Mini и Mini G. Три модели: **Original** (Специалист, 1987), **MX** (Специалист-MX, 1991) и **MX2** (Специалист-MX², «Сябр»). Модель и процессор (КР580ВМ80А или Z80) выбираются в OSD, их смена сбрасывает машину.

## Что положить на SD-карту

В корень: `specialist.kg`. В папку `/specialist`: программы и образы дисков.

| Файл | Куда в OSD | Что это |
|---|---|---|
| `.rks` | RKS file (Menu+F2) | программа, образ кассеты |
| `.odi` | Disk A (Menu+F7), Disk B (Menu+F8) | дискета MX, 800 КБ |
| `.rom`, `.bin` | Monitor (Menu+F4) | свой Монитор для Original, до 12 КБ с C000 |
| `.rom`, `.bin` | MX ROM (Menu+F5) | своё ПЗУ MX, до 48 КБ с 0000 |
| `.img` | SD card | образ SD-карты для SDOS |
| `sdos_hwmpvv.bin` | SDOS ROM | ПЗУ SDOS (Emu80 `dist/spec`) |
| `syabr_mx2.bin` | MX2 ROM | ПЗУ MX² (Emu80 `dist/specmx`) |

Монитор-2 и ПЗУ RAMFOS уже есть внутри `specialist.kg`. ПЗУ SDOS и MX² в ядро не встроены: положите их из комплекта Emu80 и выберите один раз, дальше они грузятся сами. Программы и игры в `.rks` есть в комплекте эмулятора [Emu80](https://github.com/vpyk/emu80v4): `dist/spec/sdcard/GAMES`, `dist/specmx/sdcard/exolon`.

## Первый запуск

**Original.** На экране «PROGRAM ?». Нажмите F1, затем Enter, появится «* МОНИТОР ?». Загрузите программу пунктом RKS file: она запустится сама примерно через 0,2 секунды.

**MX.** RAMFOS спрашивает дату: можно просто нажать Enter. Откроется оболочка с RAM-диском, внизу подсказки по клавишам F1–F7. F6 загружает с дискеты в приводе A. Файл `.rks` на MX тоже запускается сам, в обход RAMFOS.

Autorun = Off только загружает `.rks` в память, запускать его надо самому: на Original директивой G Монитора.

## Варианты Монитора

Пункт Monitor принимает любой Монитор Специалиста до 12 КБ: из Emu80 `spec_m1.rom` (Монитор-1), `spec_m2_qwerty.rom`, `pk01m.rom` (ПК-01М), `lik.rom` (Лик). Для Лика поставьте Keyboard = Lik (Esc на месте F1, Tab нет). Пустой выбор возвращает встроенный Монитор-2 после перезапуска ядра.

## SDOS

Ext port = SDOS, SDOS ROM = `sdos_hwmpvv.bin`, SD card = `sd_spec.img` из Emu80 (2 МБ, там большая часть программ Специалиста). Только модель Original. В Мониторе наберите `GD000`: появится `A:\>`. `DIR` — каталог, `CD имя` — папка, `имя` — запуск.

## MX²

Model = MX2, MX2 ROM = `syabr_mx2.bin`. Стартует Монитор в режиме обычного Специалиста. Директивы: `X` — режим MX и RAMFOS, `U` — SD Shell (SD-контроллер MX² не сделан), `B` — Бейсик, `E` — редактор, `A` — ассемблер, `Z` — дизассемблер «Практик». Keyboard = Auto даёт оригинальную раскладку.

## Z80, AY, мышь

CPU = Z80 — для программ под «Специалист Z80». AY = On — AY-3-8910 на портах 14h (данные) и 15h (регистр), как в Emu80; при этом команды OUT/IN к портам ниже C0h не трогают память. Ext port = Mouse — мышь на пользовательском ВВ55 (протокол Emu80 SpecMouse), не вместе с SDOS.

## Физический дисковод (Go)

На Go в браузере Disk A / Disk B можно выбрать физический привод на разъёме платы вместо образа. Только MX. Не проверено.

## Клавиши

Раскладка позиционная, как QWERTY-режим Emu80: буквы и цифры на своих местах.

| Клавиша ПК | Специалист |
|---|---|
| Shift | НР |
| Enter | ВК |
| Backspace | ЗБ |
| Home | Курсор в начало |
| PgUp | СТР |
| PgDn, End | ПС |
| Ctrl | ПВ (только Original) |
| Insert, Caps Lock | РУС/ЛАТ |
| `=` | `:` |
| `'` | `^` |
| `` ` `` | `@` |
| F1–F11 | F1–F11 (на MX F1–F10) |

F12 — сброс (Reset в OSD), Menu+Esc — OSD. Джойстик работает как клавиши: стрелки, A — пробел, B и Start — Enter.

## OSD

| Пункт | Значения |
|---|---|
| Model (Menu+M) | Original, MX |
| CPU speed (Menu+S) | 2 МГц (как в оригинале), 4 МГц |
| Color (Menu+C) | 8 цветов, 4 цвета, моно (только Original; большинство программ чёрно-белые) |
| Autorun (Menu+A) | запускать `.rks` после загрузки |
| Video | 800 × 600 60 Гц, 720 × 576 50 Гц |

## Диски MX

Образ `.odi`: 80 дорожек, 2 стороны, 5 секторов по 1024 байта, 819200 байт. Запись сохраняется в файл на карте. Настоящий диск с ОС MX на этом ядре ещё не запускали: не нашли образ. Загрузка и запись проверены тестовыми образами (`src/sim/mkboot_odi.py`, `mkboot_rw.py`). Если есть образ с CP/M или RAMFOS, расскажите, что получилось.
