# Железо Специалиста и Специалиста-MX

Источники: Emu80 v4 (`src/Specialist.cpp`, `dist/spec/spec.conf`, `dist/specmx/spmx.conf`) и ядро Sorgelig (`Specialist.sv`). Если они расходятся, верим Emu80, расхождение отмечено **проверить**.

## Специалист (оригинал)

CPU КР580ВМ80А, 2 МГц, старт с C000 (Emu80 `cpu.startAddr`). Прерываний нет.

| Адрес | Что |
|---|---|
| 0000–8FFF | ОЗУ 36 КБ |
| 9000–BFFF | экран 12 КБ, 384 × 256: байт = 8 точек, старший бит слева; адрес = 9000h + столбец × 256 + строка (48 столбцов) |
| C000–EFFF | ПЗУ, до 12 КБ (Монитор-2: 6 КБ) |
| F000–F7FF | ВВ55 пользователя (у Emu80 `ppi1`, у Sorgelig `ppi2`) |
| F800–FFFF | ВВ55 клавиатуры (у Emu80 `ppi2`, у Sorgelig `ppi1`); адрес A1..A0 |

Sorgelig, кроме того, на сбросе показывает ПЗУ и в 0000–0FFF, пока CPU не обратится к A15 = 1. Emu80 этого не делает (старт сразу с C000). **проверить** по схеме.

### ВВ55 клавиатуры (F800)

| Порт | Направление | Биты |
|---|---|---|
| A | вывод / ввод | столбцы 0–7 матрицы 12 × 6 |
| B | ввод | PB7..PB2 = строки 5..0, PB1 = клавиша НР (0 = нажата), PB0 = вход ленты |
| C младшая | вывод / ввод | PC3..PC0 = столбцы 8–11 |
| C старшая | вывод | PC7 = выход ленты и бит цвета, PC6 = бит цвета, PC5 = бипер (и вентиль ВИ53 в MX), PC4 = бит цвета |

Клавиатура сканируется в обе стороны: программа может выставить столбцы и читать строки или наоборот (Emu80 `setHMatrixMask` / `setVMatrixMask`). Порт в режиме ввода даёт на выходах единицы.

### Цвет оригинала

Каждая запись в экран запоминает текущий цвет (PC7, PC6, PC4) для этого байта. Режимы Emu80: моно, 4 цвета (`(c & 0xC0) >> 6`), 8 цветов (`((c & 0xC0) >> 5) | ((c & 0x10) >> 4)`); фон чёрный. Палитры: `c_spec4ColorPalette`, `c_spec8ColorPalette` в Emu80. У Sorgelig R = ~PC6, G = ~PC7, B = ~PC4: **проверить** соответствие палитре Emu80.

## Специалист-MX

Страница выбирается записью в FFFC..FFFF (адрес, а не данные выбирает страницу; данные — номер RAM-диска). После сброса — ПЗУ.

| Запись | Страница |
|---|---|
| FFFC | ОЗУ |
| FFFD, данные D2..D0 | RAM-диск 0..7 |
| FFFE, FFFF | ПЗУ |

| Адрес | ОЗУ | RAM-диск | ПЗУ |
|---|---|---|---|
| 0000–8FFF | ОЗУ | диск N | ПЗУ RAMFOS (до BFFF) |
| 9000–BFFF | экран | диск N | ПЗУ |
| C000–FFBF | ОЗУ | диск N | ОЗУ (как в странице ОЗУ) |
| FFC0–FFDF | системное ОЗУ (общее) | | |
| FFE0–FFFF | устройства | | |

Устройства (A4..A2):

| Адрес | Что |
|---|---|
| FFE0–FFE3 | ВВ55 клавиатуры (биты как у оригинала, кроме цвета) |
| FFE4–FFE7 | ВВ55 пользователя |
| FFE8–FFEB | ВГ93 (wd1793) |
| FFEC–FFEF | ВИ53 |
| FFF0 | синхронизация FDD: запись останавливает CPU до DRQ или конца команды (Sorgelig `cpu_hold`) |
| FFF1 | плотность (не используется) |
| FFF2 | D0 = сторона |
| FFF3 | D0 = привод |
| FFF4–FFF7 | нет |
| FFF8–FFFB | регистр цвета: D7..D4 цвет точек, D3..D0 цвет фона (16 цветов, `c_spec16ColorPalette`) |
| FFFC–FFFF | выбор страницы |

Sorgelig держит RAM-диск в 4 страницах (BRAM), Emu80 — 8 страниц по 64 КБ − 64 байта. Делаем 8.

### ВИ53 MX

2 МГц. Канал 0 — звук; канал 1 тактирует канал 2 (Emu80 `setExtClockMode`, Sorgelig `clk_timer = {ce, ce, out1}` — **проверить**, какой канал от какого). PC5 ППА клавиатуры — вентиль звука (Emu80 `setGate`).

### Дисковод MX

ВГ93, 2 привода, 2 стороны, 80 дорожек, 5 секторов по 1024 байта (`.odi`, 800 КБ, `size_code 3` у Sorgelig).

Загрузка RAMFOS по F6: многосекторное чтение (90h) дорожки 0, стороны 0, секторов 1–5 в E400–F7FF; статус после чтения 01; [F7FF] = [F7FE] + 1; `CALL E400`, в A — аргумент драйвера.

## Файлы

- `.rks`: начальный адрес (2 байта), конечный адрес (2 байта), данные, контрольная сумма (2 байта). Sorgelig пишет `JMP начало` в 0000 и сбрасывает CPU в страницу ОЗУ. **проверить** контрольную сумму по `SpecFileLoader` Emu80.
- MX: Emu80 `SpecMxFileLoader` кладёт файлы в RAM-диск (заголовок с адресами и контрольной суммой) — формат каталога RAMFOS **проверить**.
- `.odi`: образ диска MX.
