# Ядро Специалист для Karabas Go / Mini / Mini G

[English version](README.md)

Советские домашние компьютеры **Специалист** (А. Ф. Лапин, «Моделист-конструктор», 1987),
**Специалист-MX** (НПО «Комета», 1991) и **Специалист-MX²** для плат семейства Karabas Go (Xilinx
Spartan-6 XC6SLX25). Одно ядро, три модели, выбор в OSD. Вся работа с файлами (программы, Мониторы,
ПЗУ, образы дисков и SD-карт) идёт через OSD и файловый браузер прошивки платы: своего загрузчика в
ядре нет.

| Плата | Видео | Звук | Разъём дисковода |
|---|---|---|---|
| Karabas Go | VGA | ЦАП PCM5102, бипер | физический привод A / B для MX |
| Karabas Mini | HDMI со звуком | HDMI, сигма-дельта выход | — |
| Karabas Mini G | HDMI со звуком | HDMI, ЦАП PCM5102 | — |

Файл ядра `specialist.kg` (один на все три платы) лежит в `src/` и в репозитории выпусков
[karabas-go](https://github.com/andykarpov/karabas-go) (`cores/`).

**Состояние:** сборка 26110705. Проверено на Mini G (см. [Что проверено](#что-проверено)). Сборки для
Go и Mini сделаны из тех же исходников и проходят тайминги, но на этих платах ещё не запускались.

## Три машины

| | Специалист (Original) | Специалист-MX | Специалист-MX² |
|---|---|---|---|
| Процессор | КР580ВМ80А, 2 МГц | КР580ВМ80А, 2 МГц | КР580ВМ80А, 2 МГц |
| ОЗУ | 48 КБ вместе с экраном | 64 КБ + RAM-диск 8 × 64 КБ | как у MX |
| ПЗУ | Монитор с C000 (до 12 КБ) | RAMFOS, 48 КБ | 64 КБ: Монитор-4 и ПЗУ MX |
| Экран | 384 × 256, цвет на байт из порта клавиатуры (8 цветов) | 384 × 256, 16 цветов на байт (цвет точек и фона из регистра FFF8) | цвета Специалиста в стандартном режиме, цвета MX в режиме MX |
| Накопители | магнитофон | магнитофон, дисковод (КР1818ВГ93, 800 КБ) | как у MX |
| Звук | бипер | таймер ВИ53 | таймер ВИ53 |
| Оболочка | Монитор | RAMFOS (файловый менеджер RAM-диска) | Монитор-4, RAMFOS по директиве X |

У Специалиста нет прерываний и кадровой синхронизации: программы не ждут луч, поэтому картинку
можно выводить в любом стандартном видеорежиме.

## Что умеет ядро

- **Процессор:** КР580ВМ80А (vm80a, потактовая модель кристалла) или **Z80** (T80), 2 МГц (как в
  оригинале) или 4 МГц.
- **Видео:** экран 384 × 256 читается прямо из SRAM платы, без кадрового буфера: 800 × 600 @ 60 Гц
  (точка 2 × 2 пикселя) или 720 × 576 @ 50 Гц (масштаб 3:2). Цвета Специалиста (8, 4 или моно) и 16
  цветов MX, палитры как в Emu80.
- **Клавиатура:** матрица 12 × 6, опрашивается в обе стороны, как на машине; раскладки оригинала,
  RAMFOS и Лика. USB-геймпад работает как клавиши.
- **Программы:** файлы `.rks` (образы кассет) грузятся прямо в память и запускаются сами.
- **MX:** регистр страниц (ОЗУ, RAM-диск 0..7, ПЗУ), регистр цвета, таймер ВИ53 со звуком, контроллер
  дисковода с двумя приводами `.odi` (чтение и запись, образ кэшируется в SRAM). На Go разъём
  дисковода может быть приводом A или B.
- **MX²:** его ПЗУ 64 КБ, стандартный режим с устройствами MX на F000, режим MX.
- **SDOS:** SD-адаптер HWM / PVV на F000 с SDOS на файле-образе SD-карты.
- **AY-3-8910** на портах ввода-вывода 14h / 15h, как в Emu80.
- **Мышь** Специалиста по протоколу Emu80 на пользовательском ВВ55.
- **Магнитофон:** TAPE_IN и TAPE_OUT платы для настоящего магнитофона.

Не сделано (см. `docs/BACKLOG.md`): SD-контроллер MX² и SD-оболочка vinxru (контроллер со своим
микроконтроллером), TurboSound, внешний ROM-диск MXOS / Commander.

## Быстрый старт

1. Скопируйте `specialist.kg` в корень SD-карты платы.
2. Создайте на карте папку `/specialist` и положите туда программы (см.
   [Где взять программы](#где-взять-программы)).
3. Выберите **Specialist** в меню ядер. На экране появится `PROGRAM ?`.
4. Нажмите **F1**, затем **Enter**: Монитор ответит `* МОНИТОР ?`.
5. Откройте OSD (**Menu+Esc**), выберите **RKS file** (Menu+F2) и файл `.rks`: программа загрузится и
   запустится сама.

Для MX: в OSD **Model** = MX (Menu+M). RAMFOS спросит дату, достаточно нажать Enter. Его оболочка
покажет RAM-диск, назначение функциональных клавиш написано внизу экрана.

## Где взять программы

Лучший источник — **Emu80** Виктора Пыхонина: в комплекте эмулятора есть программы, ПЗУ и образы для
Специалиста. Скачайте выпуск [vpyk/emu80v4](https://github.com/vpyk/emu80v4/releases) или откройте папку
`dist/` на GitHub:

| Папка Emu80 | Что | Куда в OSD |
|---|---|---|
| `dist/spec/sdcard/GAMES` | 127 игр (`.rks`) | RKS file |
| `dist/spec/sdcard/SOFT` | 30 программ: Бейсики, ассемблеры, отладчики, Форт, музыка | RKS file |
| `dist/spec/sd_spec.img` | образ SD-карты с большей частью программ Специалиста, для SDOS | SD card |
| `dist/spec/sdos_hwmpvv.bin` | ПЗУ SDOS | SDOS ROM |
| `dist/spec/spec_m1.rom`, `spec_m2.rom`, `spec_m2_qwerty.rom` | Монитор-1, Монитор-2, Монитор-2 под QWERTY | Monitor |
| `dist/spec/lik.rom`, `pk01m.rom` | клоны Лик и ПК-01М | Monitor |
| `dist/specmx/spmx.rom` | RAMFOS (уже встроен в ядро) | MX ROM |
| `dist/specmx/syabr_mx2.bin` | ПЗУ MX² | MX2 ROM |
| `dist/specmx/sdcard/exolon` | Exolon в четырёх версиях: `exolonmx.rks` (MX, 16 цветов), `exolon8c.rks`, `exolon4c.rks` (цветной Специалист), `exolonbw.rks` | RKS file |

Ещё: [UnivEngineer/Specialist-OS](https://github.com/UnivEngineer/Specialist-OS) — ОС для MX на основе
Commander (MXOS) и RAMFOS, игры в `assets/games`.

**Форматы:** `.rks` — файл кассеты: начальный и конечный адрес, данные, контрольная сумма (`E6` и имя
перед ними тоже понимаются). `.odi` — диск MX: 80 дорожек × 2 стороны × 5 секторов по 1024 байта =
819200 байт. `.img` — образ SD-карты (FAT) для SDOS.

## SD-карта

```
/specialist.kg
/specialist/
    *.rks                программы (RKS file)
    *.odi                диски MX (Disk A, Disk B)
    sd_spec.img          образ SD-карты для SDOS (SD card)
    sdos_hwmpvv.bin      ПЗУ SDOS (SDOS ROM)
    syabr_mx2.bin        ПЗУ MX² (MX2 ROM)
    lik.rom, ...         другие Мониторы (Monitor)
```

Монитор-2 и RAMFOS встроены в `specialist.kg`. ПЗУ SDOS и MX² не встроены: выберите их в OSD один
раз, дальше прошивка грузит их при каждом запуске ядра. Выбранный файл запоминается; **Del** в OSD
сбрасывает выбор (пункт ПЗУ после перезапуска ядра возвращает встроенное ПЗУ).

## Как пользоваться

### Специалист и его Монитор

После `PROGRAM ?` нажмите F1 и Enter. Полезные директивы Монитора-2: `D<начало>,<конец>` — дамп
памяти, `G<адрес>` — запуск, `R` — чтение с магнитофона. Карта памяти и порты описаны в
[docs/HARDWARE.md](docs/HARDWARE.md).

**Программы:** RKS file (Menu+F2). При **Autorun = On** после загрузки 0,2 с работает Монитор (он
настраивает порт клавиатуры и свои переменные, как после настоящего включения), затем программа
запускается со своего начального адреса. При Autorun = Off программа только загружается: запустите
её директивой `G<адрес>`.

**Другие Мониторы:** пункт Monitor принимает любой Монитор до 12 КБ с адреса C000: Монитор-1,
Монитор-2 QWERTY, ПК-01М, Лик. Для Лика поставьте **Keyboard = Lik** (Esc на месте F1, Tab нет).

**Цвет:** цветной Специалист запоминает 3 бита цвета (PC7, PC6, PC4 порта клавиатуры) для каждого
байта, записанного на экран. Пункт **Color** выбирает, как их показывать: 8 цветов, 4 цвета или моно.
Большинство программ чёрно-белые, но есть и цветные версии (например, `exolon8c.rks`).

### Специалист-MX и RAMFOS

Model = MX. RAMFOS стартует из страницы ПЗУ, спрашивает дату и показывает RAM-диск (до 8 × 64 КБ).
Функциональные клавиши: F1 — копирование, F2 — удаление, F3 / F4 — загрузка и запись на магнитофон,
F5 — редактор, F6 — загрузка с дискеты, F7 — отладчик. Keyboard = Auto ставит функциональные клавиши
туда, где их ждёт RAMFOS.

Файлы `.rks` работают и на MX: файл кладётся в основное ОЗУ (так же, как в ядре MiSTer), а при Autorun
машина переключается на страницу ОЗУ и переходит к программе. Так запускаются программы MX с цветом и
звуком ВИ53, например `exolonmx.rks`.

**Дискеты:** Disk A (Menu+F7) и Disk B (Menu+F8) принимают образы `.odi`, запись сразу попадает в файл
на SD-карте. F6 в RAMFOS загружается с привода A: RAMFOS читает дорожку 0 (пять секторов в E400) и
запускает её, если это системный диск. Образа настоящего системного диска MX при разработке найти не
удалось; диск с CP/M, RAMFOS или Bridge Panels должен работать — будем рады отчёту.

**Своё ПЗУ MX:** пункт MX ROM (Menu+F5) заменяет RAMFOS любым ПЗУ до 48 КБ. ПЗУ MXOS и Commander из
Emu80 требуют ещё внешний ROM-диск на ВВ55, которого в ядре нет.

**Физический дисковод (Go):** в файловом браузере Disk A или Disk B прошивка предлагает привод на
разъёме Go вместо образа. Это модель КР1818ВГ93 с сепаратором данных: 5 секторов по 1024 байта, 80
дорожек, обе стороны. На железе ещё не проверено.

### Специалист-MX²

Model = MX2, MX2 ROM = `syabr_mx2.bin`. Стартует `МОНИТОР-4:` в стандартном режиме (карта памяти и
цвета Специалиста). Директивы: `X` — режим MX и RAMFOS, `B` — Бейсик, `E` — редактор, `A` —
ассемблер, `Z` — дизассемблер (набор «Практик»), `U` — SD-оболочка (нужен SD-контроллер MX², его в
ядре нет). Keyboard = Auto даёт оригинальную раскладку.

### SDOS на образе SD-карты

Model = Original, Ext port = **SDOS**, SDOS ROM = `sdos_hwmpvv.bin`, SD card = `sd_spec.img`. В
Мониторе наберите `GD000`: SDOS напишет свою версию и `A:\>`. `DIR` — каталог, `CD <имя>` — смена
папки, `<имя>` — запуск программы; длинный каталог ждёт нажатия клавиши после каждой страницы. В
`sd_spec.img` лежит большая часть программ Специалиста по папкам (`GAMES`, `SYSTEM`). Так же работает
любой FAT-образ, сделанный для адаптера HWM / PVV. SDOS занимает F000–F7FF, поэтому пользовательский
ВВ55 и мышь при этом отключены.

### Z80

CPU = Z80 (машина сбрасывается). Для Z80-версий программ («Специалист Z80» в Emu80); Монитор и SDOS на
нём тоже работают. Ввод-вывод Z80 доходит только до устройств; порты C0h–FFh, как и на 8080,
отображаются на память по адресу {n, n}.

### AY

AY = On: AY-3-8910 на 1,75 МГц, номер регистра в порту 15h, данные в порту 14h (чтение тоже), как в
Emu80. Пока он включён, OUT / IN в порты ниже C0h перестают писать в память по адресу {n, n}. На
настоящей машине OUT туда пишет, и программа может на это рассчитывать: для таких программ AY лучше
выключить.

### Мышь

Ext port = **Mouse**: USB-мышь на пользовательском ВВ55 (F000 у Специалиста, FFE4 у MX) по протоколу
Emu80: спад PB0 выдаёт на порт A следующий байт пакета `7F, 08 | кнопки, dx, dy, dz`. Для программ,
написанных под неё.

### Магнитофон

TAPE_IN платы подключён к PB0 порта клавиатуры, PC7 — к TAPE_OUT: подпрограммы магнитофона Монитора и
RAMFOS работают с настоящим магнитофоном (ещё не проверено). На MX выход магнитофона, как в Emu80,
слышен и в звуке.

### Видео

**Video** = 800 × 600 @ 60 Гц (по умолчанию, картинка 768 × 512) или 720 × 576 @ 50 Гц (576 × 512,
частота кадров оригинала). Переключается в любой момент, OSD остаётся по центру.

## Меню OSD

OSD открывается **Menu+Esc**. Файловые пункты открывают браузер в `/specialist`. Смена Model или CPU
сбрасывает машину, остальные переключатели действуют сразу.

| Пункт | Значения | Горячая клавиша | Что делает |
|---|---|---|---|
| Disk A, Disk B | образ `.odi` или физический привод (Go) | Menu+F7, Menu+F8 | дисководы MX / MX² |
| SD card | `.img` | | образ SD-карты для SDOS |
| RKS file | `.rks` | Menu+F2 | грузит программу в основное ОЗУ (Autorun её запускает) |
| Monitor | `.rom`, `.bin` | Menu+F4 | Монитор Специалиста с C000 вместо Монитора-2 |
| MX ROM | `.rom`, `.bin` | Menu+F5 | ПЗУ MX вместо RAMFOS |
| SDOS ROM | `.bin` | | ПЗУ SDOS (нужно для Ext port = SDOS) |
| MX2 ROM | `.bin` | | ПЗУ MX² (нужно для Model = MX2) |
| Model | Original, MX, MX2 | Menu+M | машина |
| CPU | KR580VM80A, Z80 | | процессор |
| CPU speed | 2 MHz, 4 MHz | Menu+S | 2 МГц — как в оригинале; ВИ53 всегда на 2 МГц |
| Keyboard | Auto, Original, RAMFOS, Lik | Menu+K | раскладка; Auto = RAMFOS на MX, Original в остальных |
| Color | 8 colors, 4 colors, Mono | Menu+C | цвета Специалиста (не MX) |
| Ext port | None, Mouse, SDOS | | что подключено к пользовательскому порту |
| AY | Off, On | | AY на портах 14h / 15h |
| Autorun | On, Off | Menu+A | запускать `.rks` после загрузки |
| Video | 800x600 60Hz, 720x576 50Hz | | видеорежим |
| Reset | | F12 | сброс машины |

Ctrl+Alt+Backspace возвращает в загрузочное меню платы (прошивка).

## Сборка

Клонируйте с `--recursive` (модули плат лежат в сабмодуле `modules/`,
[karabas-go-modules](https://github.com/andykarpov/karabas-go-modules)) и положите рядом
[karabas-go-tools](https://github.com/andykarpov/karabas-go-tools). В ISE 14.7 `cd src && make`
собирает все три платы и `specialist.kg`, `make minig` — одну плату. `src/sim/run_boot.sh` запускает
симуляцию (verilator, ghdl); с `EMU80=<emu80v4>/dist` добавляются проверки SDOS и MX². Подробности
в [CLAUDE.md](CLAUDE.md) (английский), решения и история — в [docs/PLAN.md](docs/PLAN.md).
